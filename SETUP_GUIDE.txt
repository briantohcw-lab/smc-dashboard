=========================================================
  SMC OB CONFLUENCE — AUTO ENGINE VERSION
  No TradingView. No webhooks. No monthly fee.
  Your server computes the SMC signals itself.
=========================================================

HOW THIS VERSION WORKS:
  • Fetches live 4H + 15m candles from Twelve Data (free API)
  • Runs a Python port of the LuxAlgo SMC logic on your server
  • Detects 4H order blocks + 15m structure (BOS/CHoCH)
  • Flags pairs where price is inside a 4H OB and 15m aligns
  • Updates the dashboard automatically every few minutes

You already have Railway + GitHub set up from before, so this
is mostly REPLACING your old files with these new ones.

FREE TIER LIMITS (important):

  • 800 API credits per day
  • Each pair scan = 2 credits (one 4H call + one 15m call)
  → 6 pairs every 5 min ≈ 6×2×12×24 = stays under 800/day if
    you scan every 5+ minutes. Don't scan too many pairs too fast.

HOW TO READ IT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A card appears ONLY when price is currently inside a 4H order block.
  • Green card = bullish 4H OB (demand zone) — price dipped into it
  • Red card   = bearish 4H OB (supply zone) — price rallied into it
  • "15m struct" filled in = the 15m timeframe confirms the same
    direction (higher confluence). If blank, OB hit but 15m not yet aligned.
  • OB Depth   = how deep price is into the zone

This matches what you'd manually look for: HTF 4H AOI + LTF 15m alignment.

IMPORTANT — ACCURACY NOTE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

This is a PYTHON PORT of the LuxAlgo logic. It uses the same
method (leg-based swing pivots, BOS/CHoCH, extreme-candle order
blocks) but it will NOT be pixel-perfect identical to your
TradingView chart because:
  • TradingView and Twelve Data may have slightly different candle
    data (different liquidity providers / closing times)
  • Floating point and bar-indexing differences
  • The OB selection picks the extreme candle in the leg, same as
    LuxAlgo, but edge cases can differ

USE IT AS A SCANNER / SHORTLIST, then confirm the setup on your
actual TradingView chart before trading. Treat it as "these pairs
are worth a look right now," not as a final trade trigger.

If you find a pair flagging differently from your chart, compare
and let me know — the swing_length / internal_length parameters
can be tuned to match your chart settings (currently 50 / 5,
matching the LuxAlgo defaults).

In smc_engine.py the engine is created with:
  SMCEngine(swing_length=50, internal_length=5)

These match LuxAlgo's defaults (Swing = 50, Internal = 5).
If your TradingView indicator uses different values, edit the
matching line near the top of server.py:
  engine = SMCEngine(swing_length=50, internal_length=5)

  → Add the TWELVE_DATA_KEY variable in Railway (Step 4)

Status shows an API error / "credits"
  → You may have hit the 800/day or 8/min free limit
  → Increase SCAN_INTERVAL or reduce number of PAIRS

Dashboard loads but never shows signals
  → This is normal if no pair is currently inside a 4H OB
  → Tap SCAN NOW and check the status line updates
  → Visit /status in browser to see diagnostics & last_error

Railway build fails
  → Make sure smc_engine.py was added (server imports from it)
  → Check templates/dashboard.html is inside templates/ folder

Pairs not matching TradingView
  → Expected (see accuracy note). Use as shortlist + confirm on chart.
